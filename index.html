  1. Generate. New arms with new kinematics, grippers and visual skins, built from a handful of real arm descriptions.
  2. Certify. A design-time filter checks every arm in five layers and records which task instances it can physically do.
  3. Collect. Scripted task programs collect demonstrations on every arm that passes.
